# LLWB Application Audit

## Strict recruiter view

The LLWB call is not a generic senior-engineer vacancy. It is a consultancy requiring a deliverable: a secure, bilingual, searchable roster with registration, approval, administration, documentation, training, deployment, and post-launch support within 8–10 weeks.

Your strongest evidence is WaveMark full-stack work with React/Next.js, Node/NestJS/.NET, REST APIs, customer-facing applications, Agile delivery, QA collaboration, and customer deployment readiness. Your CV also supports AWS certification and hands-on AWS exposure, Docker, GitHub Actions, security-log analysis, vulnerability assessment, and Arabic/English/French fluency.

The main weakness is direct proof of a previously delivered directory, searchable database, bilingual platform, or NGO platform. The existing public GitHub is primarily AI/RAG, evaluation, search, automation, and computer-vision work. Those projects are useful supporting evidence, but they should not be presented as comparable roster platforms.
